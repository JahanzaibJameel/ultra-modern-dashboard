**Quantum** is a **next-generation futuristic landing page** designed to deliver an immersive digital experience through modern UI effects, smooth animations, and interactive visuals.

- ✨ Dynamic particle backgrounds powered by **Particles.js**

- 🎯 Interactive 3D hover effects
- 🚀 Floating animated UI elements
- 📱 Fully responsive, mobile-first layout
- ⚡ Lightning-fast performance with pure HTML, CSS & JavaScript

Perfect for:

# 🎨 Customization

## 🎨 Color Theme

Inside **style.css**

```css
:root {
  --primary: #00f0ff;
  --secondary: #ff00f0;
  --accent: #f0ff00;

  --dark: #0a0a12;
  --darker: #050508;
  --light: #f0f0ff;
}
```

Modify these values to instantly rebrand the website.
